# 목록형 항목은 수동 순서(order) 대신 날짜 기준 자동 정렬을 쓴다

PRD 초안(DR-04)은 education/career 같은 목록형 항목이 고유 순서값(order)을 갖고 사용자가 직접 재정렬할 수 있어야 한다고 정의했었다. 그릴링에서 검토한 결과, 이력서라는 도메인 특성상 학력·경력의 표시 순서는 거의 항상 "최신이 위로 오는" 시간순이며, 소유자가 그 순서를 임의로 뒤집을 이유가 없다는 데 합의했다. 그래서 각 항목의 `start_date`를 기준으로 항상 자동 정렬하고, 순서를 사람이 지정하는 필드·UI(드래그 정렬, 위/아래 버튼 등)는 만들지 않기로 했다.

**대안**: order 필드 + 재정렬 UI(PRD 원안). 기각 이유 — 이력서 도메인에서 실제로 쓰일 일이 거의 없는 기능에 구현 비용(DB 컬럼, 재정렬 API, 드래그 UI)을 들이는 게 낭비라고 판단.

**참고**: 이 결정으로 PRD DR-04가 v0.4에서 수정되었다 (`specs/myhub_prd.md`).
