이 프로젝트에서는 <MyHub>라는 이름의 웹 기반 CV 애플리케이션을 만들 예정이야.
Server, Client, DB로 구성된 Full stack 개인 이력서 웹 애플리케이션이고, 채용 담당자나 협업 파트너가 볼 예정이야.

- 데이터 스키마는 @myhub_fullstack_data_schema_def.md 를 기준으로 하며, 데이터별 DB CRUD를 적절히 지원해야 함
- 다음과 같은 공통 기능 요구사항을 만족해야 함
    - 이력서 열람 및 데이터별(섹션별) 렌더링
    - 관리자(소유자) 인증 후 데이터 수정/추가/삭제
    - 언어 전환 기능
    - 테마(라이트/다크 모드) 선택 기능
    - 이력서 전체 인쇄 기능
- 소유자(나) 인증 및 편집 모드에 대해 다음 요구사항 만족
    - 비밀 코드를 통한 인증만을 수행하며, `.env` 파일을 통해 관리
    - 소유자 인증 성공 시, 데이터 출력 화면에서 라이브 에디팅 모드를 지원 (별도 콘솔 연결 없음)
    - 로그아웃 시 방문자 모드로 전환되어 읽기 전용 모드로 복귀
- 실제 구현 단계에서는, 별도 컨텍스트로 제공되는 풀스택 스캐폴드 프로젝트의 코드베이스 기반으로 구현 예정
    - 상세 기술 스택 등에 대한 책임은 해당 스캐폴드에 기반함
- UI/UX 및 품질 요구사항은 추후 구현 단계에서 별도로 제공 예정
