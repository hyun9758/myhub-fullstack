# MyHub 유저스토리 명세 — MyHub Full-Stack CV

## 0. 문서 정보

### 0.1 목적
이 문서는 요구사항 그릴링(6.2)을 통해 합의된 내용을 바탕으로, MyHub 풀스택 이력서 애플리케이션의 유저스토리와 인수 조건을 명세한다. 이 문서를 읽으면 각 기능이 "무엇을 만족해야 완료인지"를 판단할 수 있고, 7장 구현·테스트 설계의 입력 자료로 그대로 사용할 수 있다.

### 0.2 범위

| 구분 | 내용 |
|---|---|
| 포함(In scope) | 언어 전환, 테마, 인쇄, Profile 열람/수정, Education CRUD, Career CRUD, Skills 열람/수정, **Projects CRUD (v0.2.0, 8.1 신규 추가)**, 이력서 열람·탐색, 소유자 인증(로그인/로그아웃/세션) |
| 제외(Out of scope) | Intro, Publications, Awards 도메인(여전히 범위 밖 — PRD USG-05/09/10). 배열 항목의 수동 재정렬(그릴링으로 자동 정렬로 대체됨, PRD DR-04 v0.4 참조) |

### 0.3 독자
- **개발**: 각 유저스토리의 인수 조건을 구현 대상으로 삼는다 (7장 coding-agent의 입력).
- **QA**: 인수 조건을 E2E 테스트 케이스(7.2)로 변환한다.
- **기획(소유자 본인)**: 그릴링 합의 결과가 문서에 정확히 반영됐는지 확인한다.

### 0.4 ID 체계

| 종류 | 형식 | 예시 | 규칙 |
|---|---|---|---|
| 유저스토리 그룹 | `USG-<그룹번호 2자리>` | `USG-01` | PRD의 `myhub_usg_list.md` 번호를 그대로 승계 (범위 밖 그룹은 결번으로 남김) |
| 유저스토리 | `USG-<그룹번호>-US-<스토리번호 3자리>` | `USG-01-US-001` | 그룹 내에서 001부터 순차 증가 |
| 인수 조건 | `USG-<그룹번호>-US-<스토리번호 3자리>/AC<n>` | `AC01` | 유저스토리 내에서 01부터 순차 증가 |

- 이 문서는 단일 파일이므로 `<영역>` 값은 `A`로 고정된다.
- ID는 한 번 부여하면 재사용/재번호 매기지 않는다. USG-05, 09, 10(Intro/Publications/Awards)은 범위 밖이라 결번으로 남긴다. USG-08(Projects)은 v0.1.0에서는 결번이었으나 8.1(신규 기능 추가)에서 v0.2.0으로 채워졌다.

| 역할 ID | 역할명 | 설명 | 권한 범위 |
|---|---|---|---|
| `ACT-VISITOR` | 방문자 | 별도 로그인 없이 이력서를 열람하는 채용 담당자/협업 파트너 등 | 모든 섹션 읽기 가능(민감정보 제외), 쓰기 불가 |

## 3. 유저스토리

### USG-01. 언어 전환

- **목적:** 방문자·소유자가 이력서를 원하는 언어로 이해할 수 있게 한다.
- **범위:** 전역 언어 토글과 선택 유지. 번역 자동화는 포함하지 않는다.
- **제약사항:** 지원 언어는 한국어/영어 2개로 한정한다.

#### USG-01-US-001. 언어 전환하기

**스토리**
> ACT-VISITOR/ACT-OWNER로서, 이력서를 한국어 또는 영어로 보고 싶다.
> 내가 편한 언어로 정보를 이해하기 위함이다.

**인수 조건**

- **USG-01-US-001/AC01**: **Given** 이력서 화면을 보고 있을 때/**When** 언어 토글을 누르면/**Then** 모든 텍스트가 선택한 언어로 즉시 바뀐다.
- **USG-01-US-001/AC02**: **Given** 언어를 선택한 뒤/**When** 페이지를 새로고침하거나 재방문하면/**Then** 마지막으로 선택한 언어가 그대로 유지된다.
- **USG-01-US-001/AC03**: **Given** 특정 필드에 현재 언어 값이 비어 있을 때/**When** 화면이 렌더링되면/**Then** 다른 언어 값으로 대체(fallback)되어 표시된다.

---

### USG-02. 화면 밝기(테마)

- **목적:** 방문자·소유자가 눈에 편한 화면 밝기를 선택할 수 있게 한다.
- **범위:** 라이트/다크 토글과 선택 유지, 시스템 설정 감지.
- **제약사항:** 해당 없음.

#### USG-02-US-001. 테마 전환하기

**스토리**
> ACT-VISITOR/ACT-OWNER로서, 화면을 라이트 또는 다크 모드로 바꾸고 싶다.
> 내 눈에 편한 환경에서 이력서를 보기 위함이다.

**인수 조건**

- **USG-02-US-001/AC01**: **Given** 이력서 화면을 보고 있을 때/**When** 테마 토글을 누르면/**Then** 배경·글자 색상이 즉시 전환된다.
- **USG-02-US-001/AC02**: **Given** 테마를 선택한 뒤/**When** 재방문하면/**Then** 마지막 선택 테마가 유지된다.
- **USG-02-US-001/AC03**: **Given** 한 번도 직접 선택한 적이 없을 때/**When** 처음 접속하면/**Then** 시스템(OS) 다크모드 설정을 따른다.

---

### USG-03. 인쇄 / PDF 저장

- **목적:** 방문자·소유자가 이력서를 오프라인에서 공유·제출할 수 있게 한다.
- **범위:** 브라우저 인쇄 기능 활용. 서버사이드 PDF 생성은 포함하지 않는다.
- **제약사항:** 해당 없음.

#### USG-03-US-001. 인쇄/PDF 저장하기

**스토리**
> ACT-VISITOR/ACT-OWNER로서, 지금 보고 있는 이력서를 인쇄하거나 PDF로 저장하고 싶다.
> 오프라인에서 공유하거나 제출하기 위함이다.

**인수 조건**

- **USG-03-US-001/AC01**: **Given** 다크 모드로 보고 있을 때/**When** 인쇄를 실행하면/**Then** 인쇄 결과는 라이트 모드 기준으로 출력된다.
- **USG-03-US-001/AC02**: **Given** 인쇄를 실행했을 때/**When** 결과물을 확인하면/**Then** 네비게이션·토글 등 화면 전용 요소는 제외되어 있다.
- **USG-03-US-001/AC03**: **Given** 편집 모드(로그인 상태)에서 인쇄했을 때/**When** 결과물을 확인하면/**Then** 입력창·저장 버튼 등 편집 UI는 제외되어 있다.
- **USG-03-US-001/AC04**: **Given** 특정 언어로 보고 있을 때/**When** 인쇄하면/**Then** 현재 선택된 언어 기준으로 출력된다.

---

### USG-04. Profile

- **목적:** 이력서의 기본 정체성 정보를 열람·관리한다.
- **범위:** 프로필 조회(민감정보 접근 제어 포함) 및 소유자 수정.
- **제약사항:** `birth`/`address`/`militaryService`는 방문자에게 비공개(PRD UR-13, v0.4 그릴링 신설).

#### USG-04-US-001. 방문자가 프로필 열람하기

**스토리**
> ACT-VISITOR로서, 이력서 주인의 기본 프로필을 보고 싶다.
> 어떤 사람인지 빠르게 파악하기 위함이다.

**인수 조건**

- **USG-04-US-001/AC01**: **Given** 이력서 화면을 열었을 때/**When** 프로필 영역을 확인하면/**Then** 사진·이름·직무 뱃지·이메일·모바일·소속·소셜 링크가 표시된다.
- **USG-04-US-001/AC02**: **Given** 방문자 모드일 때/**When** 프로필 영역을 확인하면/**Then** 생년월일·주소·병역 필드는 노출되지 않는다.
- **USG-04-US-001/AC03**: **Given** 필수가 아닌 특정 필드 값이 비어 있을 때/**When** 렌더링되면/**Then** 해당 필드만 개별적으로 숨겨진다.

#### USG-04-US-002. 소유자가 프로필 수정하기

**스토리**
> ACT-OWNER로서, 로그인한 뒤 내 프로필 정보를 그 자리에서 고치고 싶다.
> 최신 정보로 유지하기 위함이다.

**인수 조건**

- **USG-04-US-002/AC01**: **Given** 로그인한 상태에서/**When** 프로필 편집을 시작하면/**Then** 생년월일·주소·병역을 포함한 모든 프로필 필드가 입력 가능한 상태로 바뀐다.
- **USG-04-US-002/AC02**: **Given** 값을 고치고 저장을 눌렀을 때/**When** 저장이 성공하면/**Then** 변경된 값이 즉시 화면에 반영된다.
- **USG-04-US-002/AC03**: **Given** 필수 필드(이름 등)를 비운 채/**When** 저장을 시도하면/**Then** 저장이 거부되고 오류 사유가 표시된다.
- **USG-04-US-002/AC04**: **Given** 저장 도중 세션이 만료되어 있을 때/**When** 저장을 누르면/**Then** 로그인 화면으로 안내되고 입력하던 값은 유지된다.

### USG-06. Education

- **목적:** 학력 이력을 열람·관리한다.
- **범위:** 조회(공개) + 소유자의 생성/수정/삭제. 표시 순서는 시작일 자동 정렬(수동 재정렬 없음, PRD DR-04 v0.4).
- **제약사항:** 해당 없음.

#### USG-06-US-001. 방문자가 학력 열람하기

**스토리**
> ACT-VISITOR로서, 이력서 주인의 학력을 확인하고 싶다.
> 학업 배경을 파악하기 위함이다.

**인수 조건**

- **USG-06-US-001/AC01**: **Given** 이력서 화면에서/**When** 학력 섹션을 보면/**Then** 학교·학위·전공·기간이 시작일 최신순으로 나열된다.
- **USG-06-US-001/AC02**: **Given** 학력 데이터가 하나도 없을 때/**When** 화면을 렌더링하면/**Then** 학력 섹션 자체가 보이지 않는다.

#### USG-06-US-002. 소유자가 학력 추가하기

**스토리**
> ACT-OWNER로서, 새로운 학력 한 건을 추가하고 싶다.
> 최신 학업 이력을 반영하기 위함이다.

**인수 조건**

- **USG-06-US-002/AC01**: **Given** 로그인한 상태에서 "학력 추가"를 눌렀을 때/**When** 필수 항목(학교·학위·시작일)을 입력하고 저장하면/**Then** 새 항목이 목록에 날짜순으로 삽입된다.
- **USG-06-US-002/AC02**: **Given** 종료일을 비운 채 저장했을 때/**When** 목록에서 확인하면/**Then** 해당 항목은 "재학 중"으로 표시된다.
- **USG-06-US-002/AC03**: **Given** 필수 항목을 비운 채/**When** 저장을 시도하면/**Then** 저장이 거부되고 오류 사유가 표시된다.

#### USG-06-US-003. 소유자가 학력 수정/삭제하기

**스토리**
> ACT-OWNER로서, 기존 학력 항목을 고치거나 지우고 싶다.
> 잘못된 정보를 바로잡기 위함이다.

**인수 조건**

- **USG-06-US-003/AC01**: **Given** 로그인한 상태에서 항목의 "수정"을 눌렀을 때/**When** 값을 고치고 저장하면/**Then** 목록에 변경 내용이 즉시 반영된다.
- **USG-06-US-003/AC02**: **Given** 항목의 "삭제"를 눌렀을 때/**When** 확인 팝업에서 확인하면/**Then** 해당 항목이 목록에서 사라진다.
- **USG-06-US-003/AC03**: **Given** 비로그인 상태에서 수정/삭제 API를 직접 호출할 때/**When** 요청을 보내면/**Then** 서버가 401로 거부한다.

### USG-07. Career

- **목적:** 경력 이력을 열람·관리한다.
- **범위:** 조회(공개) + 소유자의 생성/수정/삭제. Education과 동일한 CRUD 패턴을 따른다.
- **제약사항:** 해당 없음.

#### USG-07-US-001. 방문자가 경력 열람하기

**스토리**
> ACT-VISITOR로서, 이력서 주인의 경력을 확인하고 싶다.
> 실무 경험을 파악하기 위함이다.

**인수 조건**

- **USG-07-US-001/AC01**: **Given** 이력서 화면에서/**When** 경력 섹션을 보면/**Then** 기관·역할·설명·기간이 최신순으로 나열된다.
- **USG-07-US-001/AC02**: **Given** 경력 데이터가 하나도 없을 때/**When** 화면을 렌더링하면/**Then** 경력 섹션 자체가 보이지 않는다.

#### USG-07-US-002. 소유자가 경력 추가/수정/삭제하기

**스토리**
> ACT-OWNER로서, 경력 항목을 추가하거나 고치거나 지우고 싶다.
> 최신 실무 이력을 반영하기 위함이다.

**인수 조건**

- **USG-07-US-002/AC01**: **Given** 로그인한 상태에서 "경력 추가"를 눌렀을 때/**When** 필수 항목(기관·기간·역할)을 입력하고 저장하면/**Then** 새 항목이 목록에 추가된다.
- **USG-07-US-002/AC02**: **Given** 기존 항목을 수정하고 저장했을 때/**When** 목록을 확인하면/**Then** 변경 내용이 즉시 반영된다.
- **USG-07-US-002/AC03**: **Given** 항목을 삭제했을 때/**When** 확인 팝업에서 확인하면/**Then** 해당 항목이 목록에서 사라진다.
- **USG-07-US-002/AC04**: **Given** 비로그인 상태에서 쓰기 API를 직접 호출할 때/**When** 요청을 보내면/**Then** 서버가 401로 거부한다.

### USG-08. Projects (v0.2.0, 8.1 신규 추가)

- **목적:** 수행한 프로젝트 이력을 열람·관리한다.
- **범위:** 조회(공개) + 소유자의 생성/수정/삭제. Education/Career와 동일한 CRUD 패턴을 따른다. 참조 링크(GitHub 등)를 항목별로 여러 개 첨부할 수 있다.
- **제약사항:** 표시 순서는 연도(`year`) 최신순 자동 정렬(ADR-0001 원칙 적용, 수동 재정렬 없음).

#### USG-08-US-001. 방문자가 프로젝트 열람하기

**스토리**
> ACT-VISITOR로서, 이력서 주인이 수행한 프로젝트를 확인하고 싶다.
> 실제 수행 역량과 결과물을 파악하기 위함이다.

**인수 조건**

- **USG-08-US-001/AC01**: **Given** 이력서 화면에서/**When** 프로젝트 섹션을 보면/**Then** 구분(팀/개인)·연도·기간·프로젝트명·역할·설명이 연도 최신순으로 나열된다.
- **USG-08-US-001/AC02**: **Given** 프로젝트에 참조 링크(GitHub 등)가 있을 때/**When** 항목을 보면/**Then** 링크 버튼이 함께 표시되고 새 탭에서 열린다.
- **USG-08-US-001/AC03**: **Given** 프로젝트 데이터가 하나도 없을 때/**When** 화면을 렌더링하면/**Then** 프로젝트 섹션 자체가 보이지 않는다.

#### USG-08-US-002. 소유자가 프로젝트 추가/수정/삭제하기

**스토리**
> ACT-OWNER로서, 프로젝트 항목을 추가하거나 고치거나 지우고 싶다.
> 최신 수행 이력을 반영하기 위함이다.

**인수 조건**

- **USG-08-US-002/AC01**: **Given** 로그인한 상태에서 "프로젝트 추가"를 눌렀을 때/**When** 필수 항목(프로젝트명·구분·연도·역할)을 입력하고 저장하면/**Then** 새 항목이 목록에 추가된다.
- **USG-08-US-002/AC02**: **Given** 기존 항목을 수정하고 저장했을 때/**When** 목록을 확인하면/**Then** 변경 내용이 즉시 반영된다.
- **USG-08-US-002/AC03**: **Given** 항목을 삭제했을 때/**When** 확인 팝업에서 확인하면/**Then** 해당 항목이 목록에서 사라진다.
- **USG-08-US-002/AC04**: **Given** 비로그인 상태에서 쓰기 API를 직접 호출할 때/**When** 요청을 보내면/**Then** 서버가 401로 거부한다.

### USG-11. Skills

- **목적:** 보유 기술·언어 능력을 열람·관리한다.
- **범위:** 조회(공개) + 소유자의 통째 수정(단일 객체형, PRD DR-03). 개별 항목 CRUD API는 두지 않는다.
- **제약사항:** 해당 없음.

#### USG-11-US-001. 방문자가 스킬 열람하기

**스토리**
> ACT-VISITOR로서, 이력서 주인의 기술 스킬과 언어 능력을 확인하고 싶다.
> 보유 역량을 파악하기 위함이다.

**인수 조건**

- **USG-11-US-001/AC01**: **Given** 이력서 화면에서/**When** 스킬 섹션을 보면/**Then** 기술 스킬 목록과 언어 능력(언어명+숙련도) 목록이 표시된다.
- **USG-11-US-001/AC02**: **Given** 스킬 데이터가 비어 있을 때/**When** 화면을 렌더링하면/**Then** 스킬 섹션 자체가 보이지 않는다.

#### USG-11-US-002. 소유자가 스킬 수정하기

**스토리**
> ACT-OWNER로서, 기술 스킬 목록과 언어 능력을 갱신하고 싶다.
> 최신 역량을 반영하기 위함이다.

**인수 조건**

- **USG-11-US-002/AC01**: **Given** 로그인한 상태에서 스킬 편집을 시작했을 때/**When** 항목을 추가/삭제하고 저장하면/**Then** 변경된 전체 목록이 저장되고 화면에 반영된다.
- **USG-11-US-002/AC02**: **Given** 비로그인 상태에서 수정 API를 직접 호출할 때/**When** 요청을 보내면/**Then** 서버가 401로 거부한다.

### USG-12. 이력서 열람 및 탐색

- **목적:** 방문자가 원하는 정보를 빠르게 찾을 수 있게 한다.
- **범위:** 섹션 앵커 네비게이션, 반응형 레이아웃.
- **제약사항:** 해당 없음.

#### USG-12-US-001. 방문자가 섹션 간 이동하기

**스토리**
> ACT-VISITOR로서, 원하는 섹션(프로필/학력/경력/스킬)으로 빠르게 이동하고 싶다.
> 필요한 정보만 골라 보기 위함이다.

**인수 조건**

- **USG-12-US-001/AC01**: **Given** 이력서 화면 상단 네비게이션에서/**When** 섹션 메뉴를 누르면/**Then** 해당 섹션으로 스크롤 이동한다.
- **USG-12-US-001/AC02**: **Given** 데스크톱/모바일 화면 폭에서/**When** 화면을 열면/**Then** 레이아웃이 화면 크기에 맞게 반응형으로 표시된다.

### USG-13. 소유자 인증 및 데이터 라이브 편집

- **목적:** 소유자만 별도 콘솔 없이 이력서 화면에서 직접 데이터를 관리할 수 있게 한다.
- **범위:** 비밀 코드 로그인, 세션 유지·만료, 로그아웃.
- **제약사항:** 세션 유효기간 7일(PRD TR-11 v0.4). 아이디/비밀번호, 소셜 로그인 등 다른 인증 수단은 범위 밖.

#### USG-13-US-001. 소유자가 로그인하기

**스토리**
> ACT-OWNER로서, 비밀 코드만으로 로그인하고 싶다.
> 별도 아이디 없이 간단히 내 이력서를 관리하기 위함이다.

**인수 조건**

- **USG-13-US-001/AC01**: **Given** 방문자 모드에서 "관리자 로그인"을 누르고 올바른 비밀 코드를 입력했을 때/**When** 로그인이 성공하면/**Then** 현재 화면이 그대로 편집 모드로 전환된다.
- **USG-13-US-001/AC02**: **Given** 잘못된 비밀 코드를 입력했을 때/**When** 로그인을 시도하면/**Then** 로그인이 거부되고 방문자 모드가 유지된다.
- **USG-13-US-001/AC03**: **Given** 로그인 세션이 발급되었을 때/**When** 7일이 지나면/**Then** 세션이 자동 만료된다.

#### USG-13-US-002. 소유자가 로그아웃/세션 만료 처리하기

**스토리**
> ACT-OWNER로서, 편집을 마치면 로그아웃하고 싶다.
> 다른 사람이 내 세션으로 접근하지 못하게 하기 위함이다.

**인수 조건**

- **USG-13-US-002/AC01**: **Given** 편집 모드에서 로그아웃을 눌렀을 때/**When** 로그아웃이 완료되면/**Then** 방문자 모드(읽기 전용)로 즉시 복귀한다.
- **USG-13-US-002/AC02**: **Given** 세션이 만료된 상태에서/**When** 저장을 시도하면/**Then** 로그인 화면으로 안내되고 편집 중이던 입력값은 유지된다.
